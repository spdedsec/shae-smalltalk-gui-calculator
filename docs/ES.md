# SHAE — Documentación en Español

## Instalación
Ejecute `scripts/install.sh` para instalar la herramienta CLI.

## Plataforma
Herramienta de línea de comandos (CLI). No es una aplicación de escritorio.

## Build
`make build` compila el proyecto.

## Release
GitHub Release v0.1.0 disponible.

## Diseño
Sigue el SHAE Field Manual: papel cálido #F2EEE5, tinta #191712, óxido #B3341B, 0px de radio, bordes de 1px.
